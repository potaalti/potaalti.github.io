# Pota Altı BSL Fantezi Ligi

Türkiye Sigorta Basketbol Süper Ligi (BSL) için 17 takımlık, tamamen çevrim içi draft usulü fantezi lig.

- Kurayla belirlenen sırayla canlı yılan draft (seçim başına 1,5 dk, süre dolunca otomatik seçim)
- Takım başına 7 oyuncu: As 3 Ön + 2 Arka, 2 Yedek (mevki serbest); As'ta ve Yedekte en az 1'er Türk oyuncu
- Sezon boyunca sınırsız takas, 2 serbest oyuncu, 1 As–Yedek değişikliği
- Haftalık ve genel puan durumu BSL verimlilik (VP) puanlarından
